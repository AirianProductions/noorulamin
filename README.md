# Noor Ul Amin — Personal Portfolio

A cinematic, 3D-inspired personal developer portfolio built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The GitHub Pages workflow is included at `.github/workflows/deploy.yml`. It keeps the `/noorulamin/` base path and includes the Vite executable permission fix.

Your profile details and social links are in `src/data/profile.js`; your portrait is `public/profile.png`.
